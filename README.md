# AWS Job Application Portal

A web-based Job Application Portal built using Python, Flask, MySQL, and AWS services.

## Technologies Used

- Python
- Flask
- MySQL
- AWS RDS
- Amazon S3
- Boto3

## Features

- User registration and login
- Job application submission
- Resume upload
- Resume storage using Amazon S3
- Application data stored in Amazon RDS

## Project Description

This project allows users to register, log in, apply for jobs, and upload resumes. Application data is stored in Amazon RDS, while resumes are securely stored in Amazon S3.
